# AnimeBox: полное доступное расписание и метаданные карточек

## Установка

1. Распаковать ZIP в `C:\Users\Homie\Downloads\animebox-git` с заменой файлов.
2. База Supabase уже обновлена в ходе этой работы. SQL вручную повторять не нужно.
3. В CMD:

```bat
cd "C:\Users\Homie\Downloads\animebox-git"
npm run cf:build
npm run cf:deploy
```

4. Открыть сайт и обновить страницу через Ctrl+F5. Первые пять минут может сохраняться старый ответ CDN рекомендаций.

## Изменения

- Календарь Shikimori показывает все валидные события в выбранном диапазоне. Отсутствие постера, записи каталога или внутреннего ID больше не исключает событие.
- Если MAL/Shikimori ID достоверно соответствует одному AnimeBox ID, ссылка ведёт на страницу AnimeBox. Если связь неизвестна или неоднозначна, ссылка ведёт на поиск названия. MAL ID никогда не подставляется вместо AniList/AnimeBox ID.
- Даты и номера серий берутся из календаря, без повторения по неделям и без вычисления вымышленных эпизодов. «План» не означает, что перевод уже доступен.
- Резервные карточки дополняются сохранёнными данными Shikimori: формат, год/месяц, статус, число серий, выпущенные серии, оценка, студии, жанры и описание.
- Сезонные и статусные фильтры работают по сохранённым метаданным. Оценка Shikimori имеет шкалу 0–10; популярность AniList не выдумывается.
- Главная и API рекомендаций используют сохранённый каталог при ошибке AniList. Сохранённые карточки отбираются представлением с подтверждённой доступностью до пагинации, без повторной проверки заблокированного источника.
- Обновлены поколения серверного кеша и проверки этих поколений.
- Таблица метаданных доступна только серверу; RLS включён, представление использует security_invoker. В ZIP нет ключей или env-файлов.

## Обновление данных в дальнейшем

Календарь обновляется действующим серверным обработчиком; при сбое используется сохранённая копия в пределах 48 часов. Также можно обновить календарь и карточки с компьютера:

```bat
node scripts/shikimori-catalog-sync.mjs
```

Команда читает `.env.local`/`.env` (`NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`) и не выводит ключи. Она сохраняет календарь, обновляет метаданные пачками до 50 тайтлов и последовательно получает подробности для доступных тайтлов с недостающими описаниями/жанрами/студиями. Интервал запросов не меньше 1,1 секунды. При ошибке API карточек выполнение прекращается; сохранённые успешные результаты остаются. Если недоступен только календарь, команда может продолжить обновление карточек с сохранённым календарём не старше 48 часов, не меняя его время сохранения. Повторный запуск пропускает свежие метаданные в течение суток и подробности в течение недели.

Быстрое обновление только списка и календаря:

```bat
node scripts/shikimori-catalog-sync.mjs --details=0
```

Новый Cron не создаётся. Команда обновления метаданных запускается вручную, она не выполняется при каждом открытии карточки.

## Проверки

```bat
node tests/shikimori-metadata.mjs
node tests/schedule-shikimori.mjs
node tests/catalog-anilist-outage.mjs
node tests/schedule-anilist-outage.mjs
node tests/player-anilist-outage.mjs
node tests/home-retention-policy.cjs
```

Опциональная проверка реальных обработчиков на настроенной базе с искусственным отказом AniList:

```bat
node tests/catalog-completeness-live.mjs
```

Она читает реальные данные Supabase; обработчик расписания может обновить сохранённый календарь при неудачном чтении кеша. Не является проверкой развернутого Cloudflare Worker.

Проверка после деплоя:

```bat
curl -i "https://animebox.sukazmaps.workers.dev/api/schedule?limit=100"
curl -i "https://animebox.sukazmaps.workers.dev/api/anime?limit=1&order=ranked"
curl -i "https://animebox.sukazmaps.workers.dev/api/recommendations?limit=20&page=2"
```

- Проверены TypeScript, ESLint, тесты отказов источников/плеера и границ расписания. Полная Cloudflare-сборка прошла: все 11 Workers меньше 3 072 KiB; самый большой — 2 464,98 KiB.

## Границы исправления

Количество событий относится к доступному календарю Shikimori, а не ко всем возможным мировым релизам. Если источник не сообщает число серий, студию или описание, поле остаётся неизвестным. Подборки сохраняют фильтры вкуса и отсутствие повторов; одинаковое количество карточек в каждом ряду не гарантируется. Прямой доступ из развернутого Cloudflare к AniList не восстановлен этим патчем; работа обеспечивается сохранёнными данными.
