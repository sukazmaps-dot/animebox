# Постоянные страницы тайтлов и общая палитра

## Проблема и критерии приёмки

Существующий публичный URL, например `/anime/sousou-no-frieren/episode/1`, не должен превращаться в 404 после деплоя, потерявшего локальный реестр SQLite. При проверке только на чтение подтверждено, что `anime_search_documents` содержит аниме 154587, точный slug и описание длиной 792 символа; SEO-индекс также содержит slug с его ID.

Если локальный реестр и стабильный парсер ID не могут разрешить URL, резолвер должен использовать постоянный каталог. Точное совпадение имеет приоритет. Старый базовый slug можно сопоставить с `base-ID` только если весь суффикс совпадает с ID кандидата и существует ровно один уникальный ID. Неоднозначные и переполненные наборы кандидатов остаются неразрешёнными. Некорректные slug не должны попадать в SQL. Сбой каталога нельзя молча превращать в окончательное решение «страница отсутствует». Запросы используют проекции, ограничение в 21 строку и сигналы отмены через 3 секунды; таблицы и политики доступа не меняются.

Обогащение страницы деталей должно использовать сохранённые поля Shikimori, даже если AniList вернул частичный объект. Сохранённые русские описания каталога и уже полные русские описания провайдера сохраняют приоритет. Кешированные описание, студия, формат, год и количество эпизодов могут восстановить страницу без живого запроса к Shikimori. Сохранённое описание не на русском также пригодно, если описание провайдера пустое. Недостающие сведения нельзя выдумывать.

Публичная оболочка должна использовать общую палитру `--ab-ui-*` в обеих темах. Цвета постера не должны перекрашивать навигацию сериала или читаемые подписи. Наложение баннера должно следовать текущей теме, а не всегда становиться чёрным. Основной текст и приглушённые подписи, проверяемые браузером, должны иметь контраст не ниже 4,5:1; на ширине 390 и 1440px не должно быть переполнения страницы.

| Расписание, трекер, оценка, Watch Together, промо Telegram | Единая карточная система из патча #193; её регрессионная проверка повторяется здесь |

| Тарифы Premium, преимущества, история поддержки, Boosty | Тот же маршрутный файл; переопределяет старый фон и основные/вторичные действия |

| Чат | Модуль меняет оболочку, поле ввода и текст; эффекты пользовательского никнейма и состояния соединения/ошибки остаются отдельными |
| Страница «Не найдено» | Локальный модуль выравнивает карточку, заголовок, пояснение и надзаголовок |
| Настраиваемые профили / демонстрации оформления Premium | Намеренно сохраняют выбранные пользователем цвета и иллюстрированные сцены |
| iframe Kodik | Отрисовка принадлежит провайдеру; патч меняет только оболочку AnimeBox |
| Административные инструменты | Не входят в этот патч публичного интерфейса |

Новый корневой CSS-импорт не добавляется. Вместо накопления ещё одного глобального слоя переопределений изменяется исходный файл старой основы. Проверка корневой архитектуры: 76 импортов, 829701 байт.

## Проверки

- `node tests/persistent-anime-route.cjs`: точное восстановление, стабильный alias, исключение префикса сезона, неоднозначные точные совпадения/совпадения по префиксу, переполнение, отсутствующие/некорректные slug и частичный отказ.
- `node tests/anime-detail-persisted-metadata.cjs`: детали из кеша без сети, приоритет каталога и сохранение полного русского описания.
- Полные prebuild-проверки `npm run build` прошли. Первоначальное несоответствие TypeScript исправлено; production `next build` повторно прошёл.
- ESLint для изменённых TS/TSX: ошибок нет, остались только существующие предупреждения об изображениях.
- `scripts/page-consistency-smoke.mjs`: 30 комбинаций маршрутов/тем/размеров для предыдущего патча.
- `scripts/section-palette-smoke.mjs`: страницы Premium/друзей для гостя и собранные CSS-фикстуры для настроек/достижений авторизованного пользователя и динамической оболочки аниме/эпизода. Проверяются выбранные отображаемые подписи в обеих темах при 390/1440px. Авторизованные изменения, реальные платежи, воспроизведение iframe провайдера и все варианты пользовательских тем профиля не входят в эту визуальную фикстуру.
