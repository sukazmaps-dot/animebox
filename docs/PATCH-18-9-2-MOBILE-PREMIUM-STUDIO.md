# Патч AnimeBox 18.9.2 — мобильная Premium Studio и социальный мини-профиль

## Цель

Сделать настройку Premium удобной на узком экране телефона, не потеряв десктопный редактор, а также показывать Premium-идентичность во всех социальных сценариях взаимодействия пользователей.

## Мобильная Premium Studio

### Плавающий живой предпросмотр

На экранах уже 768px:

- встроенный десктопный предпросмотр убирается из потока документа;
- над мобильной навигацией закрепляется плавающая кнопка (FAB);
- на кнопке показывается текущий аватар и компактный значок глаза;
- несохранённые изменения обозначаются небольшой акцентной точкой.

### Предпросмотр в BottomSheet

Нажатие FAB открывает модальную нижнюю панель BottomSheet:

- живой предпросмотр профиля Premium;
- изменения атмосферы, палитры, Hero, поверхности и никнейма применяются сразу;
- Escape, фон и явная кнопка закрытия закрывают панель;
- пока панель открыта, прокрутка body заблокирована;
- доступны действия «Продолжить редактирование» и «Сохранить»;
- режим reduced-motion отключает переход при появлении панели.

Десктопный предпросмотр и мобильная панель используют один компонент PremiumStudioLivePreview.

### Компактные элементы управления

На ширине менее 768px:

- карточки атмосферы становятся горизонтальной каруселью с привязкой прокрутки;
- сегментированные переключатели остаются в одной строке и прокручиваются по горизонтали;
- вкладки Studio также допускают горизонтальную прокрутку;
- строки эффектов располагают подпись над элементами управления;
- настройки занимают всю доступную ширину.

## Подгонка аватара под рамку уровня

Прежняя безопасная область для LVL 50 / LVL 100 была слишком маленькой.

Итоговые целевые размеры:

- LVL 10: 52%;
- LVL 25: 54%;
- LVL 50: 56%;
- LVL 75: 52%;
- LVL 100: 56%.

Одинаковая геометрия используется в полном профиле, редакторе и мини-профиле.

## Общий мини-профиль Premium

ProfilePreview — каноническая социальная карточка профиля.

Мини-профиль Premium поддерживает:

- выбранную палитру профиля;
- эффект атмосферы;
- интенсивность атмосферы;
- режимы движения Off / Soft / Live;
- характер появления;
- эффекты никнейма Gradient / Shimmer / Glow;
- характер компактного Hero;
- характер компактной поверхности;
- ауру аватара;
- статические медиа и статическую рамку достижения при выключенном Motion;
- резервный режим reduced-motion.

В мини-карточке намеренно меньше частиц, чем в полном профиле.

## Интеграция с чатом

### Общий чат

Аватар, имя пользователя и распознанные упоминания вида @ открывают ProfilePreview, не уводя пользователя сразу из разговора.

Полный профиль остаётся доступен по пути «Профиль →» внутри мини-карточки.

### Watch Together

Watch Together уже использует общий ProfilePreview для участников, аватаров и имён в чате. Поэтому улучшение мини-профиля Premium из 18.9.2 применяется и там без отдельной реализации профиля.

### Комментарии

Комментарии к эпизодам и в сообществе уже используют тот же ProfilePreview; они автоматически получают те же эффекты идентичности.

## Производительность

- новый цикл requestAnimationFrame не добавляется;
- число частиц мини-профиля ограничено и ниже, чем в полном профиле;
- на мобильном мини-профиле частиц ещё меньше;
- Motion Off отключает постоянную анимацию;
- prefers-reduced-motion отключает движение атмосферы;
- данные предпросмотра профиля хранятся в клиентском кеше 60 секунд.

## Критерии приёмки

- TypeScript проходит;
- целевой lint не имеет ошибок;
- регрессионные проверки продукта/удержания пользователей проходят;
- production build проходит;
- в Premium Studio шириной 399px не нужно прокручивать страницу обратно наверх, чтобы проверить изменения;
- варианты атмосферы на мобильном больше не образуют высокий вертикальный список;
- нажатие на профиль в общем чате оставляет пользователя в чате;
- Watch Together и комментарии используют улучшенный мини-профиль;
- аватар LVL 50 визуально заполняет внутреннее отверстие Crimson Sigil, не пересекая кольцо.

## Что проверяет Quality Gate

Проверка патча явно защищает:

- мобильную кнопку FAB и BottomSheet предпросмотра;
- общий компонент живого предпросмотра для десктопа и мобильных устройств;
- поля Premium-идентичности в API мини-профиля;
- стили атмосферы Premium в общем мини-профиле;
- интеграцию ProfilePreview с общим чатом;
- интеграцию общего мини-профиля в Watch Together;
- значения подгонки аватара для LVL 50 / LVL 100.
