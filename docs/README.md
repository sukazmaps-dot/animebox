# Документация AnimeBox

Здесь собраны архитектурные заметки, инструкции по инфраструктуре и история изменений. Начинать знакомство с проектом лучше с [README в корне репозитория](../README.md).

- [RU Gateway](../infra/ru-gateway/README.md) — отдельный сетевой шлюз и его конфигурация.

## История разработки

Документы вида `PATCH-*.md`, `patch-*.md`, `HOTFIX-*.md` и файлы в `patches/` содержат планы, результаты проверок и контекст отдельных изменений. Это **архив инженерных решений**, а не единая актуальная инструкция по развёртыванию.

Перед применением старой команды, SQL или конфигурации сверяйтесь с действующим кодом, миграциями и окружением.

## Правила для новых документов

- Описывать конкретную подсистему и её текущее поведение, а не только номер патча.
- Называть файлы по содержимому: `media-delivery.md`, `deployment.md` и т. п.
- Отдельно указывать предположения, проверенные результаты и незавершённую работу.
- Не включать реальные ключи, токены, персональные данные пользователей или дампы базы.
- Архивные отчёты не удалять, пока не проверены ссылки и зависимости.

Новая документация постепенно заменит разрозненные описания патчей. Перенос старых файлов будет отдельным изменением и не затронет рабочую логику сайта.
