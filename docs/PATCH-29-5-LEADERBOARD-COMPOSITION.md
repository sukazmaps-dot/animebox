# Patch 29.5 — композиция рейтинга и размеры identity-значков

## Подтверждённые проблемы
Личная позиция находится под левым пьедесталом и видна позже таблицы. Профильные кнопки призёров имеют 28px высоту. Заголовок «Завершено» не совпадает с выравниванием значений. В таблице метка «Это ты» смешана с уровнем. Текст правил длинный. Значки владельца/спонсоров получают размеры, border-radius и object-fit аватара через descendant selector .user img.

## Исправления
1. Переместить существующий personal section в начало results перед resultsColumns. Это одна копия данных; rank/time/gap/награды и API не меняются. Desktop — горизонтальная общая плашка; при <=900px статистика занимает второй ряд; при <=520px действие третий ряд.
2. Desktop-пьедестал: средняя колонка лидера 1.12fr, остальные 1fr; минимальные высоты 350/324/314px для 1/2/3, нижние границы выровнены. Высота следует содержимому. Mobile — лидер сверху, второе/третье ниже.
3. Все кнопки призёров >=44px, шрифт 12px и внутренние отступы 10×14px; текст количества серий и пояснения времени 11px с shared muted token.
4. Header и row сохраняют одинаковую grid. Третий столбец центрирован в обеих строках; время выровнено справа. Mobile-скрытие количества серий сохраняется.
5. «Это ты» — отдельный badge около имени, отдельный от строки уровня; текущая строка мягко выделена через общие surface/accent tokens.
6. Desktop board сохраняет внутренний скролл, максимум 380px, чтобы не образовывался длинный пустой участок около пьедестала. При переполнении данных все строки доступны прокруткой; keyboard focus сохраняется.
7. Правила: max-width 76ch, 12px/1.65, контейнер центрирован, текст читается слева направо без растягивания на весь экран.
8. Все local .user img selectors заменить на .user > img. Только аватар получает 30/34/38/40px и скругление; вложенный iconImage остаётся object-fit:contain и размером из UserIdentity.module.css. Значки и Premium-маркеры не увеличивают строку.

Dark/light на 320/390/768/1180/1440/1920px; 0/1/2/3 лидера, длинные ники, owner/supporter/patron с Premium-mark, current user в podium/table и вне списка. Проверить совпадение grid track/header/data, уникальный badge, порядок personal → podium/table, 44px targets, отсутствие overflow и видимость всех строк через скролл. Сезонные награды, личное время, сортировка и дружба не изменены.
TypeScript, ESLint, существующий prebuild, offline CSS/DOM geometry fixtures. CI production build. Fixture не проверяет live API и реальную выдачу наград. Deploy только после команды пользователя; rollback через revert, без миграций.

## Проверка результата
12 offline CSS/DOM fixtures (dark/light × 320/390/768/1180/1440/1920) — PASS: personal выше результатов, одинаковые grid tracks header/row, identity artwork ровно 20×20px, кнопки >=44px, лидер крупнее остальных, нет горизонтального выхода карточек.
