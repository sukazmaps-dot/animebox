# Patch 31.5 — единые края страницы тайтла

## Причины
- detail-layout.module.css: secondary явно задаёт minmax(0, 680px) при ширине основной колонки около 1160px.
- anime-route-palette.css: max-width:680px отдельно ограничивает сам рейтинг. Локальный владелец AnimePersonalPanel снимает этот предел только для панели тайтла.
- RelatedAnime дважды использует mx-auto max-w-7xl px-4 md:px-6: загрузочная заглушка и фактическая секция. md:px-6 даёт лишние 24px. Кроме того, viewport карусели добавляет горизонтальный 1px, а на мобильных ещё margin-inline:-2px. В related-секции оба смещения сбрасываются.
- line-clamp ограничивает число видимых строк, но не задаёт одинаковую занимаемую высоту. Фиксированный слот 2.8em при line-height:1.4 и flex:0 0 auto сохраняет две строки у коротких и длинных заголовков.
- Глобальное letter-spacing:-.025em на h2 рейтинга сбрасывается в локальной панели.
- title={title} на h3 запускает браузерную подсказку. CSS не управляет её расположением; атрибут удалён, полное название сохранено как aria-label ссылки.

## Изменения
Изменены существующие CSS-владельцы и JSX; нового глобального patch CSS нет. Интерактивные панели, аккордеоны и карусель используют одну ширину родителя. Ширина ряда звёзд остаётся ограниченной 440px для удобного выбора оценки. На мобильных сохраняется одна колонка.

## Проверка
Обновлена существующая route-layout matrix: реальные AnimeCard с короткими и длинными названиями внутри контролируемого DOM страницы и настоящие CSS Modules. Проверяются оба края семи блоков, высота названий, координата метаданных, отсутствие title, letter-spacing и горизонтального переполнения, включая 1920px и мобильные ширины в тёмной/светлой темах. Это проверка геометрии в Chromium, не авторизованная сессия Opera GX.

Миграций БД нет. Патч независим от ещё не слитого PR #245. Production не изменён.
