# ТЗ: чёткий hero и компактные служебные блоки

База: main 73e1164, PR #291 выпущен. Ветка: fix/home-visual-density.
Основание: пять скриншотов пользователя от 20.10.2026; часть снята с
«Версией для ПК». Боковая навигация и мелкий масштаб в этом режиме не баг.

## Цель

Убрать обрезанную карточку перехода, растягивание обложки на весь hero,
вложенные рекламные панели и большую пустую историю поддержки.
Сохранить один выбранный тайтл, настроение, ссылки, закладку, рекомендации,
платежи, авторизацию и ограниченную загрузку изображений.

## Hero

- Менять HomeTonightArtwork/HomeTonightPick, которые реально используются
  на главной; старую карусель не переписывать.
- Разделить широкий banner, специальный мобильный artwork и обычный poster.
- Banner и специальный мобильный арт сохраняют фоновую композицию.
  Обычный постер получает явный слот 2:3 без cover, размытия и обрезания:
  справа от текста на ПК, рядом с текстом на телефоне; действия идут ниже.
- Постер не перекрывает заголовок/причину и не притворяется широким артом.
  Запрашивать large/80 с sizes под реальный слот, фон — CSS, без второй копии.
- Если отдельный арт исчерпал AnimeImage recovery, переключиться на известный
  постер того же тайтла. При смене тайтла сбрасывать состояние через текущий key.
  Никаких выдуманных URL или обещаний HD для маленького исходника.
- Сохранить существующую recovery-цепочку AnimeImage, высокую приоритетность
  одной картинки, reduced motion, отсутствие автоматической смены тайтла.

## Каталог главной

- Удалить terminal «Смотреть все» из HomeAnimeRail и связанные пропсы/правила.
  Навигация остаётся в заголовках «Смотреть все» / «Расписание».
- Сохранить реальные постеры, стрелки, клавиатурную прокрутку, прогресс,
  частично видимую следующую карточку и размер карточек.

## Поддержка на главной

- Сохранить общий заголовок и единственное закрытие с текущим localStorage key.
- Убрать вложенные рамки/заливки; два компактных действия с короткой подписью.
- Цель: desktop <=130px, mobile <=200px после загрузки; кликабельные области
  минимум 44px. Нет отдельной высокой панели для кнопки закрытия.
- Сохранить DeferredMount, настройки монетизации, скрытие Telegram для
  подписчиков, ссылку/openTelegramLink и события существующих компонентов.
- Не менять платежный сценарий, донаты и инфраструктуру.

## История поддержки

- Исправить SponsorDashboard(history), а не другой SupportHistoryClient.
- Первую пустую страницу без Stars показать одним коротким empty state;
  не рисовать пустую шкалу и две отдельные панели без операций.
- Пагинация только при page >1 или hasMore. Пустая поздняя страница сохраняет
  путь назад. Пополненная история, возвраты и денежные единицы сохраняются.
- Компактные ссылки/обновление, спокойный фон, подробные правила в details.
  Вынести представление истории в CSS Module без старых sponsor-v2 селекторов.
- Не менять API, финансовые расчёты, уровни, кэш и события обновления.

## Приёмка

- Реальные React-тесты: mobile/desktop источник и переключение на poster после
  отказа арта; пустая/пополненная/поздняя пустая история, обновление и пагинация.
- Browser production fixture: темы dark/light, 360–1920px, отдельный poster
  на mobile/desktop; изображение contain/2:3, без пересечений текста/действий.
- Проверить отсутствие terminal карточки, высоту служебного блока и сохранение
  работающих ссылок/закрытия. Добавить историю в изолированный browser fixture.
- TypeScript, lint, home32, poster recovery, prebuild/build, Quality Gate.
- Не ослаблять прежние проверки; устаревшие пины менять с пояснением.
- Отдельный PR; этот запрос разрешает реализацию, слияние/деплой отдельно.
  Откат: revert PR; Cloudflare, R2 и Supabase менять не требуется.
