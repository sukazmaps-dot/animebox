# ТЗ: наполненный первый показ лент и восстановление оригинальных постеров

База: production/main c80113a. Ветка: fix/poster-origin-recovery.
Предыдущие PR #289 и #290 слиты и выпущены.

## Цель и уточнение пользователя

Неполный раздел карточек первоначально не показывать. Сначала ограниченно
добрать достаточно подходящих карточек для ширины ряда, затем раскрыть его
целиком. При нехватке кандидатов раздел остаётся скрытым. Уже показанные ряды
сохраняются при пагинации, скрытии карточки, resize и временных ошибках.
Дополнительно исправить раннее принятие миниатюр в цепочке постеров.

## Подтверждённая диагностика

- Production Worker v7 сообщает originRelayEnabled=false и r2WritesEnabled=false.
  Две пробы media вернули 204 source-soft-fail с X-AnimeBox-Origin-Error=origin-403.
  Это отказ AniList на стороне Worker, не успешная картинка и не ошибка вёрстки.
- Те же известные URL через /api/image?fallback=error&optimize=webp вернули
  настоящие декодируемые WebP: 460×650 / 47 386 байт и 230×329 / 17 720 байт.
- extraLarge/large в сохранённых данных иногда указывают на /cover/medium/
  или /cover/small/. Само имя поля не доказывает высокое разрешение.
- Прокси лучшего исходника стоял после меньших запасных изображений; успешная
  миниатюра останавливала каскад раньше доступного оригинала.
- Прежняя политика показывала короткие ряды и отдельные compact-панели.
  Новое указание пользователя меняет именно первоначальную видимость.

## Первый показ ряда

1. Измерить реальный scroll-контейнер, карточку и gap существующим helper.
   Первый показ требует заполнения viewport, минимум пять разных карточек.
   Bootstrap сохраняет существующую цель с небольшим запасом и предел 12.
2. До валидного измерения ряд не раскрывать даже при большом исходном наборе.
3. До admission скрыть заголовок, карточки, skeleton и row retry. Секция остаётся
   измеряемой, но абсолютной, нулевой высоты и вне потока; aria-hidden/inert
   исключают её из accessibility tree и навигации клавиатурой.
4. Когда все ряды скрыты, не оставлять общий заголовок над пустой лентой.
5. При достаточном числе уникальных карточек запомнить admission на сессию.
   Поздно наполненные ряды добавлять после уже показанных, без вставки сверху.
6. При изменении настроения начать новую сессию admission. Дозагрузка сама по
   себе не сбрасывает видимость, порядок и горизонтальную прокрутку.
7. До первого показа разрешено пересобрать распределение непоказанных карточек
   под измеренные лимиты. Иначе 20 кандидатов могут ошибочно распасться на три
   ряда по семь, ни один из которых не заполняет desktop viewport.
   Карточки уже показанных рядов при этом не перераспределять.
8. Позже пришедший локальный пул может наполнить скрытый ряд даже при конце
   API. Отметка прежнего bootstrap не блокирует использование новых кандидатов.
9. Сохранить один видимый feed-level retry, если весь feed временно недоступен.
   Ошибка не раскрывает пустые персональные секции; retry остаётся явным.

## Ограничения добора

- Общие cache, cursor и in-flight Promise; без запроса на каждый ряд/постер.
- Предел bootstrap: три страницы для пустого ряда, две для непустого.
- Обычная пагинация не более существующих шести hops; виртуализация 36 DOM cards.
- Ошибки не порождают автоматический бесконечный retry.
- Строгая тематичность, скрытия пользователя, фильтры и ID-дедупликация сохраняются.
- Не заполнять продолжения франшиз случайными тайтлами ради admission.

## Постеры

1. Для card/large/hero упорядочивать только известные URL: распознанный AniList
   /cover/large/ перед /medium/ и /small/; Shikimori preview после оригиналов.
   При равном уровне сохранять исходный порядок. Не угадывать новые пути,
   имена файлов, MAL соответствия и размеры, которых нет в данных.
2. После настроенных media endpoint сначала восстановить тот же лучший
   исходник через same-origin proxy с fallback=error и optimize=webp.
   Затем — существующие независимые источники и меньшие URL, в конечном счёте
   локальный placeholder. Shikimori остаётся серверным.
3. srcset выбирает тот же исходник после переупорядочивания, включая raw cascade.
4. Tiny сохраняет прежний выбор и порядок. Лестницы ширин/качества не расширять.
5. Сжатие использует существующий source-level encoder, без увеличения картинки,
   с его cache/очередью/таймаутом и возвратом исходника при неудачном сжатии.
6. Если есть только маленький исходник, сохранить возможность его показать;
   не объявлять его HD и не подменять тайтл чужим постером.

## Границы выпуска и стоимость

Только app frontend, scoped CSS Modules, URL policy, тесты и ТЗ. API-контракт,
Supabase, схема БД, Worker и R2 не меняются. MEDIA_ORIGIN_RELAY_ENABLED и новые
R2 writes не включаются: такой Worker relay создаёт отдельную нагрузку на
Railway и требует отдельной настройки/выпуска. Этот патч восстанавливает
изображение на клиентском пути и не заявляет устранение upstream 403 Worker.
Ранний proxy может увеличить его долю запросов; compressed derivative и
действующий CDN/source cache ограничивают повторную передачу крупных PNG.

## Проверки и приёмка

- Настоящий Feed: короткий terminal ответ остаётся hidden/inert, поздние
  локальные кандидаты раскрывают ряд, скрытие карточки после admission не
  сворачивает ряд, desktop с 20 кандидатами получает полный ряд вместо всех
  скрытых семикарточных распределений.
- Admission helper: реальная измеренная цель, минимум пять, дедупликация,
  reset настроения, sticky exposure, поздние ряды после ранних.
- Браузерная матрица: отдельный sparse fixture из трёх карточек при 390/1920px
  проверяет нулевую высоту, visibility:hidden, aria-hidden и inert. Normal fixture
  содержит 60 кандидатов и сохраняет прежние interaction/geometry проверки.
- URL recovery: ошибочно названный extraLarge thumbnail уступает доступному
  оригиналу; прокси оригинала стоит до меньшего URL, optimize=webp присутствует,
  srcset совпадает, при отсутствии оригинала новые URL не выдумываются.
- Сохранены real WebP decode, no-storage defaults, offline/hidden retry, source
  identity, touch momentum и отмена устаревшей сессии.
- Targeted ESLint, TypeScript, prebuild, production build, GitHub Quality Gate.
- Production SLO 99% этим fixture-тестом не измеряется; placeholder не успех.
