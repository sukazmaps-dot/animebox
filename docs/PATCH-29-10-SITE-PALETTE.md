# Patch 29.10 — единая палитра интерфейса

## Результат

Общая палитра Foundation v2 используется внутри страниц, карточек и модальных окон. Старые сине-чёрные поверхности и самостоятельные фиолетовые CTA заменены семантическими CSS-переменными в исходных файлах. Наложение дополнительных глобальных override-таблиц не требуется.

Проверены все 198 CSS-файлов в `app` и `components`; правки затрагивают 162 CSS-файл. Отдельно обработаны цвета Tailwind-классов и значения по умолчанию в компонентах. Точные пользовательские настройки Premium, изображения, декоративные рамки и металлы призовых мест сохраняют собственную идентичность.

## Изменённые области

- Награда лиги: графитовая поверхность, единый CTA вместо сине-фиолетового градиента, читаемые описания и подписи.
- Профиль: идентичность, статистика, аниме-витрина, жанровые полосы, достижения и редактор используют общие поверхности и акценты.
- Обычный мини-профиль: старые серверные значения цвета больше не переопределяют стандартную тему.
- Premium: общие компоненты внутри персонального профиля наследуют выбранные цвета только внутри `.premium-profile-custom`. Это не перекрашивает оболочку сайта.
- Истёкший Premium: публичный профиль не подключает сохранённую персональную гамму как активную.
- Рейтинг, друзья, чат, настройки, главная, каталог, страницы просмотра, совместные комнаты, авторизация, служебные страницы и административные панели: заменены локальные старые цвета.
- Chrome theme-color и Telegram chrome используют новый графитовый фон.
- Исправлен неопределённый `--ab-ui-surface-raised` в панели здоровья рейтинга.

## Правила дальнейшей разработки

1. Использовать семантические переменные вместо локальных HEX для интерфейса.
2. Слой карточки выбирать по роли: Surface или Raised. Для выделения использовать Selected.
3. `Primary` предназначен для главного действия; `Accent` — для текста, иконок и состояния.
4. Полупрозрачный цвет получать через `color-mix` от токена. Не хранить новый независимый оттенок RGB.
5. Не снижать контраст пояснений через произвольную opacity; использовать Muted.
6. Цвета иллюстраций, наград, рамок и пользовательских пресетов являются отдельным контрактом. Аудит не требует уничтожения их палитр.

## Проверки

- `palette:check`: разбирает все CSS-файлы, запрещает основные выведенные из употребления UI-оттенки, проверяет объявление всех используемых UI-токенов и переключение палитры обычного мини-профиля.
- `site-palette-smoke.cjs`: реальный исходный каскад CSS, 2 темы × 2 ширины (390/1440), контраст проверяемых подписей >= 4,5:1, поверхности, CTA и сохранение произвольной Premium-гаммы. Это изолированные UI-фикстуры, а не проверка реальных аккаунтов.
- `section-palette-smoke.mjs`: 16 комбинаций собранных страниц/тем/ширин; авторизованные области представлены CSS-фикстурами.
- `chat-frame-layout-smoke.cjs`: 105 комбинаций рамок/ширин/масштаба без нарушения геометрии.
- Сравнение AST изменённых CSS с предыдущей версией: свойства геометрии не меняются.
- Полный prebuild и production build, TypeScript.
- ESLint изменённых TSX: остаются 4 исходные ошибки `set-state-in-effect` в AnimeImageCascade, HomeHero и ProfileMediaReviewClient. Проверка исходных файлов из HEAD подтверждает, что эти ошибки предшествуют патчу; новые ошибки не добавлены. Их исправление требует отдельной работы с жизненным циклом компонентов.

Объём root CSS в исходниках увеличился из-за выражений с токенами. При этом измеренный gzip общего root-каскада уменьшился приблизительно с 151,5 КБ до 142 КБ. Число root-импортов не увеличено. Бюджет исходников скорректирован до 900 КБ и дополнен gzip-бюджетом 152 КБ.

## Ограничения проверки и выкладки

Изолированные визуальные проверки подтверждают перечисленные элементы, а не каждый возможный пользовательский пресет и состояние страницы. Рекомендуется заключительная проверка авторизованных сценариев на опубликованном preview.

Миграции БД и изменения сохранённых цветов пользователей не нужны. Этот патч подготовлен отдельно от предыдущих изменений рейтинга; production-деплой выполняется отдельным действием.
