# Патч 21.2 — глобальная перестройка компоновки и читаемости интерфейса

## Цель

Завершить глобальную переработку фронтенда, начатую в production-патче 21, не объединяя отдельную ветку рекомендаций патча 22.

## Контракт

- Гибкая типографика на основе rem/clamp вместо фиксированных размеров шрифта в пикселях.
- Для длинного текста — ограничение примерно до 60–75 символов в строке.
- Перекомпоновка при масштабе браузера 200–400% и узком viewport без горизонтальной прокрутки страницы.
- Сетки каталога и трекера используют гибкую геометрию CSS Grid вместо фиксированного числа колонок на контрольных ширинах.
- Длинные названия аниме переносятся максимум на две стабильные строки, не нарушая высоту карточки.
- Основной текст и элементы управления мобильной версии остаются размером не менее 1rem.
- Рекламные поверхности Telegram и каталога подстраиваются под содержимое и не расширяют viewport.
- Два первых видимых постера каталога загружаются с высоким приоритетом; остальные используют общий планировщик загрузки при приближении к viewport.
- Доставка постеров согласует AVIF/WebP через конвейер picture/srcset/sizes, сохраняя резервную логику медиа-узла AnimeBox.
- Существующее поведение для 2K/4K и Watch Together остаётся изолированным от этого патча.

## Проверка

`npm run patch21-2:check` входит в prebuild и проверяет итоговый объединённый CSS-слой, относительную типографику, гибкую геометрию каталога, контракт приоритетной загрузки постеров и источники форматов picture. Патч намеренно встроен в `patch17-4-2-ui-precision.css`, чтобы не увеличивать импортируемые в корне CSS-объёмы и бюджеты исходников.
