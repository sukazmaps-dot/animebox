# Patch 14.3 — Home & Discovery

## Goal

Turn AnimeBox Home into a media/editorial feed rather than a collection of rounded dashboard cards.

The patch keeps recommendation, history, schedule and retention logic intact. It changes composition and presentation.

## Continue Watching

Continue Watching is now the first practical action after the hero.

Desktop uses one structural shelf instead of multiple glowing cards. On phones, cards form a horizontal rail with a partial next-card peek so the surface feels continuous rather than like one giant card per screen.

Episode labels use human sentence case.

## Discovery scene

Mood selection and Smart Recommendations now form one compositional scene:

Mood -> What to watch next -> personalised poster rail.

The scene uses editorial separators rather than nested panel shells.

## Mood picker

Desktop keeps a quiet utility row. Mobile uses a compact horizontal rail instead of large boxed controls. Iris is reserved for the selected mood.

## Smart recommendations

Recommendation cards are poster-first:

- no enclosing glass card;
- tighter title/meta hierarchy;
- restrained match/rating chips;
- simple plan action;
- Open chrome appears only on desktop hover and is hidden on touch.

## Hero

The cinematic hero remains, but mobile height and copy density are reduced so Continue Watching enters the useful viewport sooner.

## Section rhythm

Catalogue sections use consistent editorial spacing and dividers instead of adding more parent cards.

## Mobile priority

The intended phone order is:

1. Hero / title discovery
2. Continue Watching
3. Quick product navigation
4. Retention/personal signals when available
5. Mood + recommendations
6. Broader catalogue content

## Scope

This patch does not change recommendation ranking, watch history storage, schedule fetching or API behavior.

14.4 will focus on Catalog/Search UX.
