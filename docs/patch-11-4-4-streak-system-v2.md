# Patch 11.4.4 — Streak System v2

## Цель
Превратить серию активности из декоративной картинки с числом в полноценную
геймификационную систему AnimeBox, которая одинаково читается в полном профиле,
mini-profile и на странице заданий.

## UX
- Один прозрачный фирменный flame WebP без чёрного квадратного фона.
- Огонь визуально меняется по состоянию серии, а не заменяется набором файлов.
- 0 дней — отдельное неактивное состояние, а не «ярко горящий огонь с нулём».
- Нормальные русские формы: 1 день / 2 дня / 5 дней.
- Отдельно показывается личный рекорд.
- Прогресс-rail означает путь до следующего milestone, а не притворяется
  историей конкретных дней недели.
- Подсказка объясняет, что 10 минут подтверждённого просмотра запускают или
  сохраняют серию.
- Если активность за сегодня уже засчитана, интерфейс это показывает.

## Уровни
- inactive: 0
- warm: 1–2
- active: 3–6
- hot: 7–13
- blazing: 14–29
- legendary: 30+

## Milestones
1 → 3 → 7 → 14 → 30 → 60 → 100, затем шаг 30 дней.

## Поверхности
1. Полный профиль — большой StreakDisplay с flame, основной цифрой, рекордом и
   milestone progress.
2. Mini-profile — compact StreakDisplay без «карточки внутри карточки» и без
   отдельного квадрата вокруг flame.
3. /challenges — тот же компонент, чтобы механика и формулировки не расходились.

## Данные
Patch использует существующий authoritative challenge snapshot:
- current
- longest
- lastActiveDate
- todayKey

Новая БД или миграция не требуется. День по-прежнему засчитывается только
существующей challenge-логикой подтверждённого просмотра.

## Performance
- Один WebP asset.
- Состояния реализуются CSS filter/drop-shadow/opacity.
- Нет постоянных тяжёлых keyframe-анимаций.
- prefers-reduced-motion не получает дополнительных движущихся эффектов.
