# AnimeBox

Аниме-каталог с персональными списками, рекомендациями и совместным просмотром. Проект развивается как самостоятельный веб-сервис.

**[Открыть AnimeBox](https://youranimebox.com)** · [Код на GitHub](https://github.com/sukazmaps-dot/animebox)

## Что есть в проекте

- Каталог аниме: поиск, фильтры, страницы тайтлов и расписание выхода серий.
- Личные профили, библиотека, оценки и сохранение прогресса просмотра.
- Рекомендации с учётом предпочтений пользователя.
- Просмотр через интегрированный внешний плеер и комнаты совместного просмотра.
- Комментарии, достижения и социальные функции.
- Telegram-бот и Mini App.

## Локальный запуск

Нужен **Node.js 22** и npm.

```bash
git clone https://github.com/sukazmaps-dot/animebox.git
cd animebox
npm ci
```

Создай локальный файл окружения:

- Windows CMD: `copy .env.example .env.local`
- PowerShell: `Copy-Item .env.example .env.local`
- macOS/Linux: `cp .env.example .env.local`

Затем настрой локальный Supabase или отдельный тестовый проект. Шаблон намеренно использует localhost, чтобы локальный запуск не подключался незаметно к встроенному fallback-проекту. Заменяй примерный publishable key на ключ своего локального/тестового проекта. Не используй реальные production-секреты.

Запусти приложение:

```bash
npm run dev
```

Сайт будет доступен на [localhost:3000](http://localhost:3000). Без настройки тестовых сервисов авторизация, функции пользователя и некоторые интеграции могут быть недоступны. В `.env.example` перечислены основные переменные; не все интеграции нужны для работы над каждой задачей.

## Проверки

```bash
npm run lint
npm run security:check
npm run css:inventory:check
```

`npm run build` запускает большой набор предварительных проверок и может занимать заметное время. Для Pull Requests также используется GitHub Actions Quality Gate. В описании PR указывай проверки, которые действительно запускал, и не отмечай пропущенные проверки как успешные.
